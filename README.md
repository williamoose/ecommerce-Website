# Second-Hand Fashion Marketplace (Personal Project)

This is a personal full-stack web development project built to explore and apply core
software engineering concepts through a marketplace-style application. The platform
allows users to create, manage, and browse second-hand fashion listings, similar to
real-world e-commerce systems.

The project emphasises clean frontend–backend integration, database-driven design,
and practical feature implementation rather than production-level completeness.

---

## Project Highlights

- Built a full-stack marketplace application using **React, TypeScript, Express.js, and PostgreSQL**
- Designed and implemented **RESTful APIs** to support user authentication and listing management
- Implemented complete **CRUD functionality** for second-hand fashion listings
- Developed structured browsing experiences including **discover, new arrivals, category-based views, and search**
- Designed relational database schemas to support users, listings, likes, and cart data
- Applied **Git and GitHub** for version control and incremental development

---

## Project Motivation

I built this project to gain hands-on experience developing a full-stack web application
from scratch. Through this project, I aimed to:

- Apply React and TypeScript in a non-trivial, real-world style application
- Design and implement RESTful APIs using Express.js
- Work with a relational database (PostgreSQL) to manage structured data
- Understand how typical marketplace features are designed and connected end-to-end
- Improve code organisation, version control, and debugging skills

---

## Features

### User Authentication
- User registration and login
- Authenticated access to protected features

### Listings Management
- Create second-hand clothing listings
- Update existing listings
- Delete listings
- Listings support multiple fields including:
  - Item name
  - Price
  - Images
  - Categories and additional details

### Browsing & Discovery
- Discover page showcasing available items
- New arrivals view to sort items by time listed
- Category-based browsing 
- Search functionality by item name

### User Pages
- Profile page displaying all listings created by the user
- Liked items page
- Shopping cart to support a checkout flow (Payment integration  planned for a future release)
